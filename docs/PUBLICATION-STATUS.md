# Release status and history

- **RC6.2:** the first publicly shared installer, with the known Repeat One defect. Preserved on GitHub as a historical prerelease. Its GitHub publication date is the date of this repository publication, not a claim about the original upload date.
- **RC7:** the newer published release candidate, with the Repeat One repair and optional crossfading. Both versions are marked prereleases rather than stable releases.
- The existing website still offers RC6.2 according to the project owner; publishing on GitHub does not change that website.

The preserved Git history begins with RC7 engineering-source import and documentation checkpoints. The RC6.2 branch imports the matching preserved source snapshot; it is not invented chronological development history. Release timestamps have not been backdated.

The unknown original dark-theme creator remains credited without an invented identity or permission grant. Our own subsequent contributions use 0BSD; see `LICENSE-SCOPE.md` for third-party exclusions.
