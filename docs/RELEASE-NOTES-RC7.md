# Enhanced Zune 1.0.0 RC7

Preserved installer release; repository preparation does not alter it. Adds optional crossfading and repairs repeat-one selection/playlist behavior while retaining earlier visual, local-photo, Mixview and installer improvements. See the changelog and limitations before installing.

Release assets: the installer, original engineering-source ZIP, frozen payload ZIP for source checkouts, and SHA-256 checksums. Original Microsoft Zune media is not included. The frozen payload must be placed at `build/payload.zip` to rebuild the installer.

Source availability is partial across the historical enhancements. Please read `docs/SOURCE-COVERAGE.md`; do not describe this as the complete open-source Zune application.
