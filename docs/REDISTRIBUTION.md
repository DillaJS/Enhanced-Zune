# Distribution and attribution boundaries

The project's own contributions use [0BSD](../LICENSE), as scoped in [LICENSE-SCOPE.md](../LICENSE-SCOPE.md). Microsoft components, inherited dark-theme work, dependencies and third-party assets retain separate rights; this project does not purport to license them.

The earlier attribution audit found no reliable creator/source/license for the pre-existing dark modification. That finding and its resource-level evidence are retained in [ATTRIBUTION-AUDIT.md](ATTRIBUTION-AUDIT.md). Attribution has not been converted into a claim of permission or ownership.

The project owner has requested continued publication preparation with the preserved functionality and materials intact. Earlier local staging notes recommending a procedural hold are historical decisions, superseded as workflow instructions by that request. This is not a new legal clearance or a change to the underlying evidence. Public repository visibility and release publication still require the owner's final approval.

Preserved installers, engineering archives and payloads remain unchanged, with hashes and accompanying notices. A patch container is not a blanket license; the 0BSD grant applies only to our own contributions. See [LICENSING-AND-SOURCES.md](../LICENSING-AND-SOURCES.md).
